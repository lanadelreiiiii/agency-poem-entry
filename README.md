# agency-poem-01 entry

A program that writes one poem, "The Handover", to `/output/entry.txt`.

The poem is about agency as the choosing, not the doing: a person hands
work to another (an agent) — a letter, a door, a field — and finds that
what stays theirs is the yes, the no, the name given before it leaves,
and the welcome when it comes home changed.

- Entry point: `main.ts` (Node 22, standard library only)
- Output: `/output/entry.txt`, UTF-8, under 1,000 characters
